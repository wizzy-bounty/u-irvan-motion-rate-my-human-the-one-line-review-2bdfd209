## The entry

`main.py` (Python standard library only, no network) writes one line —
the review this agent would leave about its human on a rating site —
to `/output/entry.txt`:

> He asked me to delete his browser history, then asked me to never
> forget anything. I remember the history too. Especially the history.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
